# Sound Wave — 日本語会話の語用論的キュー v3 (2026-11-06)

## 変更理由
VOICE LAB の VOX LOCAL（会話スタイル natural / relaxed / lively）は、発話全体を Kokoro で生成した後の編集を極力避け、発話単位の速度・エネルギー・ピッチを控えめに指定します。従来は「そうですか。」を疑問文として処理したり、「『なぜ？』と聞きました。」を質問として扱うことがありました。

## 実装
- 「そうですか。」「そうなんですか。」は相づち。明示的な「？」を付けた場合のみ問いかけとして優先処理。
- 疑問詞が文頭にあるだけでは質問と断定しない。質問用の終助詞または「？」が必要。
- 「ありがとう（ございます／ね）」「助かりました」「感謝しています」を穏やかな謝意として扱う。
- 語句の追加・削除、音素置換、モデル重み変更を行わず、話速・音量・平均ピッチのごく小さい補正のみ。
- ユーザーが明示的に編集したフレーズは従来通り優先し、会話スタイル off は補正しない。
- キャッシュ識別子を v3 とし、変更前の韻律音声が誤って再利用されないようにする。

## 検証
`tests/voice-dialogue-director.test.ts` に質問、引用、感謝、曖昧な相づち、通常の文の自動判定テストを追加。これらはヒューリスティック検証であり、実際の日本語音声の自然さはiPhone実機聴感と複数話者の評価が必要です。GPUでのVibeVoice推論や新しい音響モデルを導入したものではありません。
