# Security Policy

## Supported version

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Please do not publish credentials, tokens, personal information, or exploit details in a public issue.

If GitHub private vulnerability reporting is available for this repository, use it to report security problems privately. Otherwise, contact the repository owner through GitHub and provide only enough public detail to establish a private reporting channel.

## Secrets policy

This repository must not contain API keys, access tokens, private keys, certificates, `.env` files, local `.npmrc` credentials, or deployment-specific private metadata. The `.gitignore` includes preventive rules for these files, but contributors remain responsible for checking commits before pushing them.
